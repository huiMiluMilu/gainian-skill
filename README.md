# jargon-explainer · 概念解释 Skill

> 一个给 [WorkBuddy](https://www.workbuddy.cn) 用的技能（Skill）。把任何晦涩难懂的词、概念、行话、缩写，讲成人话——同时给你 **专业版 + 小学生版 + 真实案例**。

## 它能做什么

对任意你丢给它的词，自动输出三段：

1. **专业解释** — 准确、标注所属领域（金融 / 技术 / 法律 / 科学…）、必要时给出处与相近概念区分。拿不准的术语会先核实再写。
2. **通俗解释（小学生也能懂）** — 零术语、用生活类比（食物 / 玩具 / 动物 / 学校），7–10 岁孩子能复述；附一条孩子也能懂的"不过要记住"提醒。
3. **案例** — 一个具体场景或小故事，让抽象概念变可见，优先贴近你所在的领域。

适用领域不限：金融、计算机、法律、科学、哲学、日常生词、成语、网络热词等。

## 安装

**方式一：git clone 直接到技能目录（推荐）**

```bash
git clone https://github.com/huiMiluMilu/gainian-skill.git ~/.workbuddy/skills/jargon-explainer
```

克隆下来的目录名就是 `jargon-explainer`，正好是 WorkBuddy 识别技能所需的名字。

**方式二：手动放入**

1. 下载 / 复制本仓库内容，放进一个名为 `jargon-explainer` 的文件夹；
2. 把该文件夹放到以下任一位置：
   - **用户级**（所有项目都能用）：`~/.workbuddy/skills/`
   - **项目级**（只在该团队项目内共享）：`<你的项目>/.workbuddy/skills/`
3. 重启 / 刷新 WorkBuddy 对话即可生效。

> 无需任何额外依赖，无需联网。解释内容由 WorkBuddy 模型生成。

## 使用

在 WorkBuddy 任意对话里直接说，例如：

- "解释一下 沉没成本"
- "什么是 边际效用？"
- "帮我讲讲 API 是什么，我要给小学生听"
- "区块链 太晦涩了，讲讲"

触发后自动套用「专业解释 / 通俗解释 / 案例」三段模板。

**多义词处理**：默认采用最常见的含义并标注假设；高度多义的会先问你一句，不会乱猜。
**准确性**：涉及技术 / 金融 / 法律 / 科学且不确定时，会先核实再写，保证「专业解释」段可信。

## 输出示例

以「沉没成本」为例：

**专业解释**
沉没成本（Sunk Cost）是经济学与决策理论中的概念，指已经发生、且无论如何决策都无法收回的支出（时间、金钱、精力）。它属于"历史成本"，在理性决策中不应影响未来选择——因为过去的投入已不可逆，正确的做法是只看未来的收益与成本。

**通俗解释（小学生也能懂）**
就像你花钱买了一张电影票，进去看了十分钟发现电影很无聊。票钱已经花掉、退不回来了，这钱就是"沉没成本"。聪明的小朋友不会想"钱都花了忍着看完"，而是直接离开去看更好玩的事——因为继续坐着也不会把钱变回来。

**案例**
小明花 200 元报了吉他课，上了两节发现完全没兴趣，但还剩 8 节课。如果只因为"钱都交了"就硬着头皮上完，他会再浪费 8 周时间还不快乐——这 200 元已经沉没了。理性做法是承认损失、把剩下时间拿去做喜欢的事。公司也一样：一条已经投了 1 亿、但市场证明没前途的生产线，继续砸钱"回本"往往亏更多。
